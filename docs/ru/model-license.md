# Лицензия модели

[Проект](../../README.ru.md) · [Документация](../README.md) · [English](../en/model-license.md)

Репозиторий не содержит и не распространяет файл модели Silero. При первом запуске контейнер скачивает закреплённую русскую модель Silero v5.6 с официального хоста и проверяет её SHA-256.

Silero Models распространяются под **Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International**. У модели есть ограничение некоммерческого использования. Перед развёртыванием или распространением прочитай исходные условия:

- [Silero Models](https://github.com/snakers4/silero-models)
- [Лицензия авторов](https://github.com/snakers4/silero-models/blob/master/LICENSE)

[MIT-лицензия](../../LICENSE) относится к собственному коду и документации Bridge, а не к скачиваемой модели и сторонним зависимостям.
