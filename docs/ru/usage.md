# CLI и подготовка текста

[Проект](../../README.ru.md) · [Документация](../README.md) · [English](../en/usage.md)

## Подключить клиент

Скачай `silero-tts.py` и `SHA256SUMS` из одного [релиза](https://github.com/Krablante/silero-tts-bridge/releases). В каталоге с файлами выполни `sha256sum --check SHA256SUMS`, затем `python3 silero-tts.py --version`. В примерах ниже используется `client.py` из исходников; скрипт релиза принимает те же команды. Достаточно Python 3.10+.

Задай `SILERO_TTS_URL` и `SILERO_TTS_API_KEY` либо создай `~/.config/silero-tts/client.json`:

```json
{"base_url":"https://your-private-speech-host.example","api_key":"your-private-client-key"}
```

Права каталога — 0700, файла — 0600. `SILERO_TTS_CONFIG` или `--config` выбирает другой файл; адрес и ключ из окружения имеют приоритет над файлом. Адрес может оканчиваться на `/v1`. Для удалённого доступа используй частный HTTPS-маршрут или шифрованную частную сеть.

## Озвучить и продолжить

```sh
python3 client.py voices
python3 client.py speak book.txt --voice kseniya --format opus -o book.ogg
python3 client.py speak chapter.txt --voice xenia --no-wait
```

`speak` печатает ID перед ожиданием. Повтор с тем же текстом и параметрами использует прежнее задание. `--refresh` явно создаёт новое, сохраняя возможность повторно использовать совместимые фрагменты кеша. Файлы читаются как UTF-8 с необязательным BOM; `--encoding` меняет кодировку, `-` читает stdin.

Подставляй в команды настоящий ID из ответа:

```sh
python3 client.py list --limit 10
python3 client.py status tts_REPLACE_WITH_RETURNED_ID
python3 client.py wait tts_REPLACE_WITH_RETURNED_ID -o book.ogg
python3 client.py download tts_REPLACE_WITH_RETURNED_ID -o book.ogg
python3 client.py cancel tts_REPLACE_WITH_RETURNED_ID
python3 client.py resume tts_REPLACE_WITH_RETURNED_ID
python3 client.py clean tts_REPLACE_WITH_RETURNED_ID
```

`cancel` останавливает работу между фрагментами и прерывает кодирование. `resume` возвращает задание с теми же лимитами очереди, что действуют для новых запросов. Успешные части сохраняются, отсутствующие или повреждённые создаются заново. `clean` безвозвратно удаляет текст и результат неактивного задания; сначала дождись остановки работы. Общие фрагменты могут остаться до уборки кеша.

Ожидание по умолчанию ограничено 24 часами. Таймаут возвращает ошибку и сохраняет задание; Ctrl-C даёт код 130. Ошибочное, отменённое или истёкшее задание даёт код 1; ошибка настройки или транспорта — 2. `--no-wait` намеренно успешно возвращает активное задание. Скачивание продолжается из `.part`; готовый путь заменяется только после проверки размера и SHA-256. Для замены другого существующего файла нужен `--force`.

## Проверить произношение

```sh
python3 client.py segments tts_REPLACE_WITH_RETURNED_ID --offset 0 --limit 10
python3 client.py text tts_REPLACE_WITH_RETURNED_ID --kind source --max-chars 4000
python3 client.py text tts_REPLACE_WITH_RETURNED_ID --kind normalized --max-chars 4000
```

Вывод CLI ограничен 32 000 байтами JSON. `text` принимает до 8 000 символов и возвращает **байтовое** смещение продолжения; `segments` — до 30 частей. Полная книга не выводится автоматически. Если нужна целая копия, скачай явный HTTP-артефакт текста.

`text_mode=auto` использует закреплённый `rutextnorm` и общие правила чтения дат, годов, величин, денег, точных дробей, сокращений и технических названий. Пустые строки сохраняют жёсткие границы синтеза. Из задания доступны оригинал, подготовленные части и ограниченный список предупреждений. Координаты предупреждения относятся к исходному блоку с байтовым смещением; позиции неподдерживаемых символов — к подготовленному блоку.

Особое произношение задаётся через `--lexicon pronunciations.json`, например:

```json
{"Smith":"Смит","🦊":"лиса"}
```

Для готовой речевой копии используй `--text-mode prepared`; поддерживаются маркеры ударения вроде `к+ошка`. Цифры, латиница и другие неподдерживаемые символы по-прежнему проходят проверку. Неподдерживаемое содержимое останавливает синтез с понятной ошибкой: укажи произношение вместо незаметного удаления.

Silero v5.6 использует `?` и `!` для вопросительной и восклицательной интонации. В режиме `prepared` выделяй одно целое русское слово через `*слово*`, чтобы задать центр вопроса, или `**слово**` для произнесения с нажимом. Внутри слова можно ставить маркеры ударения. Пунктуация остаётся снаружи звёздочек; непарная разметка и выделенные фразы дают ошибку `invalid_prosody`.

```sh
python3 client.py speak --text 'Это **важно**! Ты *завтра* придёшь?' \
  --text-mode prepared --voice xenia --format opus -o expressive.ogg
```

Режим `auto` предназначен для обычного текста, включая Markdown; звёздочки в нём не управляют голосом. Обновлённая обработка русских ударений и омографов уже встроена в модель, отдельно устанавливать её не нужно.

Bridge сохраняет адреса и слова. Решение убрать ссылки, email или другой материал принимает приложение до отправки. Извлечение документов, отбор содержания и публикация остаются его задачами. Пунктуация разметки может упрощаться для речи.

Проверка нарезки сохраняет все слова подготовленного текста; подготовка внутри модели проверяется на удаление букв. Также проверяются конечные ненулевые отсчёты и полная длительность результата. Это не доказывает правильное произношение или понимание каждого имени. Bridge не вызывает ASR и LLM.
