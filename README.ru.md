# Silero TTS Bridge

[English](README.md) · [Русский](README.ru.md) · [Документация](docs/README.md) · [Релизы](https://github.com/Krablante/silero-tts-bridge/releases)

**Русская озвучка коротких ответов и целых книг на одной CPU-модели.** Bridge готовит текст, сохраняет прогресс и делит время синтеза между приложениями. Книга продолжает собираться, а короткий ответ получает свою очередь.

Для готового речевого клиента есть бинарный API, совместимый с OpenAI; для больших текстов — сохраняемые задания и комплектный CLI. У обоих входов общая модель Silero v5.5, правила произношения и кеш фрагментов без потерь. Клиенту нужен Python 3.10+; PyTorch и FFmpeg ему не нужны.

```sh
python3 client.py speak book.txt --voice kseniya --format opus -o book.ogg
```

Команда печатает ID задания, ждёт и проверяет скачанный файл. Прерывание ожидания сохраняет работу на сервере. Повтори команду, чтобы найти её снова, или используй `status`, `wait`, `cancel` и `resume`.

## Запустить локально

Нужен Docker Compose на Linux AMD64. При первом запуске сервер скачивает и проверяет модель; дальше использует сохранённую копию.

```sh
git clone https://github.com/Krablante/silero-tts-bridge.git
cd silero-tts-bridge
cp .env.example .env
docker compose up -d --wait --wait-timeout 300
python3 scripts/smoke.py
python3 client.py speak --text 'В 2026 году Python и C++ получили 45 обновлений.' --format opus -o reply.ogg
```

Адрес по умолчанию — `http://127.0.0.1:8000`. Перед подключением других хостов настрой авторизацию и частный HTTPS-маршрут. При обновлении сохраняй том `/state`: в нём исходные тексты, задания и аудио. Подробности — в [руководстве по эксплуатации](docs/ru/operations.md).

## Подключить к приложению

```sh
curl --fail-with-body http://127.0.0.1:8000/v1/audio/speech \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: first-example' \
  --data '{"input":"Привет. Проверка 42.","voice":"xenia","response_format":"opus"}' \
  --output speech.ogg
```

Голоса: `xenia`, `eugene`, `aidar`, `baya`, `kseniya`. Форматы: MP3, OGG/Opus и WAV; скорость — 0,25–4×. Для длинного текста `POST /v1/audio/jobs` сразу возвращает ID. Прогресс переживает перезапуск сервера, постоянный ключ запроса позволяет найти то же задание после потери ответа.

Числа, даты, деньги и технические названия готовятся централизованно. Оригинал и подготовленный текст доступны для проверки; особые имена можно задать словарём запроса. Неподдерживаемый ввод даёт явную ошибку. Сервер проверяет целостность файла и полноту нарезки; правильное произношение каждого слова не гарантируется.
